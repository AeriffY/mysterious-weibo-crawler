# 神秘的爬虫
判断微博某特定博文的转发区用户是否与你存在共同关注......

## 使用说明(真的有人无聊到复现这种东西吗)
本来的用途是判断微博用户"椰子鸡大火收汁"的最新博文转发区有多少人是微博用户"斑马MU"的粉丝, 由于作者懒得一个一个翻这些人比裹脚布还长的关注列表, 因此怒而创建一个小号, 该小号仅关注了"斑马MU"一人. 如此一来, 只需要查看转发区用户与作者小号是否存在"共同关注的人"即可.

首先在你的 python 环境中安装 playwright:
```bash
pip install playwright
```

第一次运行时程序会打开 Chrome, 需要手动登录微博. 登录成功后不要关闭浏览器, 程序会自动继续执行. 以后运行会自动使用保存的登录状态.
